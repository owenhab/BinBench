▶ Units
Applies to every size field in this panel. Values are always stored internally in mm — the printed template and exported files stay true to scale either way.
▶ Project unsaved
▶ Printer bed
Presets are nominal build volumes from Bambu's specs. Bambu Studio reserves a little space for the cutter and Z-hop, so knock a few mm off if you're printing right to the edge.
▶ Drawer interior
Measure the inside of the drawer, not the drawer face.
▶ Layout & walls
▶ Baseplate
The baseplate is a uniform grid of tapered sockets, one every "Grid reference" spacing (set under Layout & walls) across the whole drawer — it doesn't know or care where your bins are. Each bin grows a matching tapered foot under every grid cell it substantially covers, Gridfinity-style, so it can nest anywhere on the plate and you can rearrange bins without reprinting it. Foot taper = foot height gives a 45° self-aligning chamfer that prints without supports.
▶ Paper template
Prints the drawer footprint at true scale, tiled across sheets you tape together. Set your printer to 100% / "Actual size" (not "Fit to page"), then check the 100mm calibration bar on page 1 with a ruler before trusting it.

Drawer layout

Level
Drag an empty area to draft a bin. While a bin is selected: drag its corners to resize, drag a divider's bar to slide it, or drag a divider's round end caps to trim where it starts and stops — ends snap to the walls and to any perpendicular divider they meet. Each divider has its own height — set it below the bin's height for a low divider you can reach over. Dashed lines mean a partial-height divider. Bins snap to the drawer walls and to each other at the minimum gap — drag one up against its neighbour and it will click into place (green guide). Click a placed bin to edit it; drag it to move it. Copy a bin (button, or Ctrl/Cmd+C) and paste it (Ctrl/Cmd+V) to duplicate it into the next free spot. Use the Level tabs to stack: on level 2 and up the bins below show through as dashed ghosts, and a stacked bin has to run the full width or full depth of the one under it — an open box can only carry weight on its rim walls, so a strip bridges them but an island in the middle would have nothing to sit on.

Print-plate packing preview

Add bins to see how they'd batch across build plates.
One file with every bin already laid out, each plate tagged so Bambu Studio opens them as separate plates. Other slicers ignore the tagging and show the plates side by side instead — arrange from there.

Baseplate sections

Add bins to generate matching baseplate sockets.
Piles every section into a single job, each one turned over from the last so the socket faces meet squarely, lined up on a shared grid and biggest at the bottom. The sections are separated by an air gap, not by plastic — turn supports on and set them to everywhere, not just the build plate, and the slicer fills each gap with support that peels off to free the sections.
